# PySide6 Classic App

A classic PySide6 (Qt for Python) application setup.

## Setup

1.  **Environment**: Ensure you have Python installed.
2.  **Dependencies**:
    ```bash
    pip install -r requirements.txt
    ```
    *Note: Requires internet access to install PySide6 and tools.*

## Running the App

```bash
python main.py
```

## Testing

Run tests using pytest:

```bash
pytest
```
